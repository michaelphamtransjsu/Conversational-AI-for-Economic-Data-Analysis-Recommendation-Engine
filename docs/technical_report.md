# FRED Economic Conversation: technical report

**Validation basis: DEMO / SYNTHETIC fixtures, not empirical economic findings.** No live FRED observations or live OpenAI responses were validated. Final executed commands, counts, and artifact checks are recorded in [evaluation results](evaluation_results.md); reproducible output and metadata accompany this report.

## Objective and scope

The application answers seven economic-analysis questions through one modular Python/Streamlit interface: latest reported GDP, GDP over ten years, current Core CPI inflation, inflation over five years, the indicators' relationship, a comparison visualization, and key trends. Users can continue with contextual requests such as “use the last five years,” “now graph it,” or “now compare it with inflation.” The application preserves dates, definitions, arithmetic, and source provenance throughout those interactions.

The application belongs to [Conversational-AI-for-Economic-Data-Analysis-Recommendation-Engine](https://github.com/michaelphamtransjsu/Conversational-AI-for-Economic-Data-Analysis-Recommendation-Engine). It lives directly at the repository root, with `app.py` as the entry point, source modules under `src/fred_chat/`, and tests under `tests/`. The destination initially contained a placeholder README, so there was no existing application to integrate. The scope contains only GDP and CPILFESL. Real GDP, forecasts, historical-as-of vintages, optional series, public deployment, and authentication are excluded. This build is intended for local use by a trusted user.

## Economic definitions and transformations

FRED GDP is **nominal**, quarterly, measured in billions of dollars at a seasonally adjusted annual rate (SAAR). Its annual-rate level is not the actual dollar total produced during the quarter. CPILFESL is the **monthly seasonally adjusted Core CPI price index**, excluding food and energy, with 1982–1984=100. An index level is not an inflation percentage. Changes calculated from this seasonally adjusted series need not exactly equal every published BLS headline YoY figure.

Python implements all formulas. GDP YoY is `100*(G[q]/G[q-4]-1)`; QoQ is `100*(G[q]/G[q-1]-1)`; annualized QoQ is `100*((G[q]/G[q-1])**4-1)`. Monthly Core CPI YoY is `100*(C[m]/C[m-12]-1)` and MoM is `100*(C[m]/C[m-1]-1)`. Growth and inflation default to YoY, while the latest reported GDP question requests the level. Current inflation also includes secondary MoM at the displayed YoY period when computable. Rate changes are reported in percentage points. Level summaries state exact first/last periods, absolute change, and `100*(last/first-1)`.

Native observations are reindexed to a complete monthly or quarterly calendar before lagging. Missing dates remain missing; no forward filling or interpolation occurs. Full history supplies pre-window baselines, calculations precede display trimming, and rounding occurs only in presentation. Missing latest observations or unavailable baselines produce explicit notices when an earlier valid metric is displayed. Nonpositive baselines cannot produce percentage-change rates.

Relationship analysis uses quarterly nominal GDP YoY and YoY change of quarterly-average Core CPI. Each CPI quarter requires all three valid monthly index levels; its arithmetic mean is `Cbar[q]`. Inflation is then `100*(Cbar[q]/Cbar[q-4]-1)`, not the average of monthly YoY rates. The application inner-joins valid quarterly rates and uses precisely those rows for the chart and Pearson correlation. It requires at least eight paired quarters and rejects constant rates. The reported coefficient includes count, exact common quarters, and method. Association establishes neither causality nor predictive power; nominal GDP contains price effects, and samples, revisions, and extremes can affect results.

## Architecture and conversation control

The [architecture source and rendered diagram](architecture.md) show the implemented flow. Streamlit owns controls, cards, chat, and downloads. Pydantic schemas validate allowlisted tools. The data service supplies immutable snapshots; separate analytics and alignment modules compute a typed evidence bundle. Plotly renders named chart templates, while deterministic narrative templates render numeric answers. Each result carries its metric, units, observation window, formulas, records, summary, sources, snapshot IDs, retrieval timestamp, source update field, defaults, and limitations.

OpenAI is the implemented configurable provider, selected with server-side `LLM_PROVIDER`, `LLM_MODEL`, and `LLM_API_KEY`. The adapter uses strict structured function schemas and a fixed HTTPS endpoint. Free-form model prose is discarded. Optional explanation selects IDs of fixed notes already supported by the evidence; Python maps those IDs to text. This limits unsupported numerical and causal assertions. Provider failures leave deterministic supported prompts and dashboard calculations available with clear notices.

The orchestration budget permits at most six economic tool calls, eight model calls including note selection, and one invalid-tool repair per turn. Inputs, messages, argument sizes, responses, retained turns, and result IDs are bounded. Context remains session-local. A chart follow-up uses the exact previous evidence without retrieval. User/model inputs can choose a tool and validated arguments; they cannot execute Python, SQL, shell, expressions, or arbitrary URLs. Unsupported real-GDP and vintage requests receive explicit explanations.

## Retrieval, snapshots, and failure behavior

The FRED HTTP client retrieves metadata and complete native histories through the official series and observations endpoints with untransformed `lin` units. It validates definitions, calendar dates, finite positive values, missing markers, duplicates, pagination count/offset, and real-time interval consistency. Requests have bounded timeouts and at most three transient attempts. Retry-After guidance is respected; a server delay beyond the wait budget returns an error rather than retrying early. Missing keys, rejected credentials, network failures, malformed responses, empty ranges, and insufficient history remain distinguishable.

The six-hour default cache stores JSON, CSV, sanitized raw responses, and a manifest containing coverage, retrieval time, source updates, real-time parameters, and SHA-256 checksums. Files publish atomically, with the manifest last. Refresh preserves older snapshots; corrupt entries cannot conceal a valid fallback, and live selection excludes demo snapshots. Latest/current requests force refresh. Failure may use an earlier valid snapshot only with an explicit stale notice and its original retrieval time. Each analytical tool pins its series snapshots throughout its result. Snapshotting reproduces retrieved values, not an arbitrary historical vintage. Observation dates and source update fields are never claimed as release dates.

Secrets remain in environment variables or ignored local configuration. They are excluded from model prompts, artifacts, and public exception text. Configuration representations mask credentials, FRED HTTP logging redacts key-bearing query values, and conversation export redacts known keys. No credentials are browser inputs. Initial implementation and validation performed no push, merge, deployment, or unrelated paid service use. The user subsequently authorized committing the completed application and pushing it to `main`, and explicitly identified the destination repository linked above. That authorization does not include public deployment.

## Evaluation, artifacts, and observed results

Offline tests exercise formulas, calendar gaps, missing baselines, trailing nulls, quarterly completeness, unequal monthly baselines, exact paired samples, short/constant series, invalid schemas, injection attempts, API failures, retry bounds, cache refresh/revisions/integrity, stale fallback, and conversation isolation. Provider tests use mocked structured responses. Streamlit AppTest exercises startup, dashboard labels, supported conversation, and follow-ups. Final pass/skip counts are reported in the evaluation record rather than estimated here.

Executed sample conversations cover all seven rubric questions, contextual follow-ups, and failure behavior. Three required chart exports accompany their CSV/evidence: GDP level over ten years, monthly Core CPI YoY over five years, and the shared quarterly YoY comparison. Captions preserve units, exact coverage, transformations, sources, snapshot timestamps, and synthetic status. HTML embeds Plotly JavaScript for offline portability. PNG export was tested with pinned Kaleido 0.2.1's bundled renderer after Kaleido 1.2.0 failed with the available browser. The older renderer emits deprecation warnings; future browser/runtime compatibility remains a portability limitation.

All generated observations are deterministic synthetic fixtures spanning 2010–2025. Fixture timestamps document provenance and do not represent live retrieval. Their trends and correlation demonstrate computational behavior only. **No empirical conclusion about U.S. GDP, inflation, or current economic conditions is supported by this validation.**
