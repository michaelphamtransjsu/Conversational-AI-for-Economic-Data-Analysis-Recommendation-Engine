# DEMO / SYNTHETIC data — not empirical economic findings

All observations in this directory are generated by `fred_chat.demo.demo_snapshot`, not downloaded from FRED. The fixed timestamp 2026-01-15T12:00:00+00:00 is fixture metadata, not a live retrieval or a publication date.

The analytical CSVs repeat units, formulas, source URLs, snapshot IDs, requested windows, and provenance on every row. Their matching `.evidence.json` files contain complete computed evidence. Raw full-history snapshot CSVs under `snapshots/` must be read with their adjacent `manifest.json` and `snapshot.json`; these manifests label DEMO data and preserve source definitions and checksums.

GDP chart: 2016Q1–2025Q4, 40 quarters. Core CPI chart: 2021-01–2025-12, 60 months, YoY calculated from pre-window history. Comparison: 2016Q1–2025Q4, 40 paired quarters, nominal GDP YoY versus YoY change of complete quarterly-average CPI. These are reproducibility examples, not findings about the U.S. economy.
